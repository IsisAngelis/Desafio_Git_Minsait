# aulajsminsait

Objetivo geral: Construir uma página com uso de HTML, CSS e Java Script.

●	A página deve conter elementos HTML, CSS e JavaScript
●	 A página deve conter dois campos USUÁRIO e SENHA e um botão de ENTRAR

●	O cabeçalho e rodapé deve ser o mesmo usado na página inicial contida no projeto disponibilizado.

●	A página deve ser aberta após o clique no botão de “login” já existente na página inicial, conforme imagem abaixo.
●	Todos os campos devem ser obrigatórios.

●	Ao clicar em ENTRAR, faltando algum campo a ser preenchido, deve se exibir um alerta (método alert()), indicando que o respectivo campo faltou ser preenchido. Mensagem: “Campo [?] é obrigatório”.

●	Caso todos os campos estejam preenchidos, deve-se fazer uma verificação via JavaScript se os dados preenchidos correspondem a um usuário e senha já estabelecidos. Caso os dados sejam compatíveis, deve-se exibir uma caixa de diálogo informando que o “Login foi realizado com sucesso”.
